# Issue tracker

Use local Markdown under `.scratch/<feature-slug>/`, ignored by Git.
Move lasting conclusions and supporting records into `docs/` when needed.

- Spec: `spec.md`.
- Tickets: `issues/<NN>-<slug>.md`, numbered from `01`, one file per ticket.
- Record triage state near the top as `Status: <label>`.
  Use the labels in `triage-labels.md`.
- Append discussion under `## Comments`.
- To publish a spec or ticket, create its file at the corresponding path.
- To fetch a ticket, read its file. Resolve bare numbers within the feature.
